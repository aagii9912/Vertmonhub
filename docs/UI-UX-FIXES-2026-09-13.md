# UI/UX audit-ийн хэрэгжүүлэлт — 2026-09-13

Mobbin audit-ийн Attio маягийн жагсаалт/дэлгэрэнгүй, Intercom маягийн inbox, Zillow маягийн шүүлтүүрийг одоогийн component, token, API дээр хэрэгжүүлэв.

## Өөрчлөлт

- Лидийн split самбар зөвхөн 1024px-ээс дээш; утас, tablet дээр Sheet нээгдэнэ. Хэмжээ өөрчлөхөд сонгосон лид хадгалагдана. Самбарын өндөр, дотоод scroll хязгаартай.
- Гар утасны анхаарах дөрвөн ангиллыг компакт болгож, тайлбарыг дэлгэж уншдаг болгов. Хайлтын талбар болон шүүлтүүрийн хүрэх талбайг томруулав.
- Inbox гар утсанд жагсаалт/яриаг тусдаа харуулж, буцах үйлдэлтэй болов. Desktop дээр зэрэгцээ хэвээр. `?conversation=` нь яг сонгосон хүнийг нээнэ; хуучин картын холбоосууд ID дамжуулна.
- Inbox ачаалалт, хоосон, олдоогүй, дахин ачаалах, илгээх алдааны төлөвтэй. Илгээх алдаанд текст талбарт үлдэнэ. Query cache байгууллагаар тусгаарлагдсан. Write/delete эрхийн UI хязгаарлалттай.
- Байрны блокийг төлөв, өрөө, код, талбайгаар шүүнэ. Давхрын тор/хүснэгтийн сонголт, үр дүнгийн тоо, шүүлтүүр цэвэрлэх үйлдэлтэй. Торын текст томорч, нэгжийн код харагдана. Гэрээний үнийг зарын үнэ гэж ашиглаагүй.
- Floating feedback-ийг header дахь нэртэй тусламжийн товч болгов. HTTP алдаа болон хадгалалтын алдааг амжилт гэж харуулахгүй; API хадгалж чадаагүй бол 500 буцаана.
- Лид, уулзалтын маягтын давхар close товчийг арилгав. Лидийн талбаруудад accessible нэр, Sheet-д тайлбар нэмэв.
- Байгууллагын самбарын нэр «Самбар», хувийн горим «Өнөөдөр». Header-ийн ерөнхий «Шинэ» нь «Лид нэмэх» болов; утасны доод нэмэх товчтой давхцахгүй. Header scroll хийхэд харагдана.
- Авлагын карт төлбөрийн хуваарьт суурилдгаа тайлбарлана. Гэрээний төлөлт нь мөнгөн орлогын тайлан биш гэдгийг ялгав. Авлагын дэлгэрэнгүй холбоос зөв contract route нээнэ.
- Маркетингийн тоймын валют/хугацаа нь тодорхойгүй зарын нийлбэрийг идэвхтэй кампанит ажлын тоогоор сольж, бүртгэлийн хамрах хүрээ болон 500 мөрийн хязгаарыг ил болголоо. Ачаалалтын алдаанд дахин оролдоно.
- Тайлангийн хэсгийн зарим нэршлийг «Лид» болгон нэгтгэв.

## Хүрээ ба үлдсэн зүйл

Санхүүгийн хоёр эх үүсвэрийн өгөгдлийг нэгтгээгүй; UI дээр утга, хамрах хүрээг нь ялгасан. Маркетингийн бүрэн хугацааны тайлан болон 500-аас олон бүртгэлийн aggregation энэ өөрчлөлтөд ороогүй. Inbox API-ийн одоогийн жагсаалтын хязгаар хэвээр: жагсаалтаас гадуурх ID нь «олдсонгүй» төлөв үзүүлнэ. Систем даяарх нэр томьёо/contrast-ийн бүрэн шинэчлэл хийгдээгүй.

Өмнө нэмэгдсэн dashboard recovery, төлбөр, AI өөрчлөлтүүдийг хадгалсан. Энэ ажил production deploy, push, бизнесийн өгөгдлийн өөрчлөлт хийгээгүй.

Анхны audit ба харагдах байдлын баримт: `output/ui-audit-2026-09-13/`. Browser-ийн зарим mobile capture нь viewport-ийг буруу хэмжээгээр экспортлосон тул screenshot-ийг дангаар нь хэмжээсийн нотолгоо болгохгүй; дээрх DOM хэмжилт болон regression тестийг ашиглана.
