# ERP-ийн бүтээгдэхүүний экспортоос байр ба гэрээ (Elysium)

Огноо: 2026-10-05 (Улаанбаатар). Салбар: `feat/elysium-erp-units-contracts`.

**Төлөв:** код, тест бэлэн. Production-д импорт **хийгээгүй** (эзэмшигчийн зөвшөөрөл хүлээж байна). Урьдчилсан шалгалт: 540 байр (Б1 408, Б2 132), 77 гэрээ.

## Асуудал

Elysium Residence-ийн «Хурлын бэлтгэл» ERP snapshot-оос (`erp_imports`) уншдаг тул байр, гэрээ харагддаг байсан. Харин «Байр» (`property_units`) ба «Гэрээ» (`property_contracts`) хуудас хоосон: ERP файлыг эдгээр хүснэгтэд хэзээ ч оруулаагүй, оруулах гэвэл импорт бүх мөрийг татгалздаг байсан:

1. «Блок» багана алга, Б1 ба Б2 нэг файлд (импорт нэг файлд ганц блок зөвшөөрдөг).
2. Excel-ийн хөвөгч таслалын үлдэгдэл (`89.32000000000001`).
3. Зогсоол/агуулахын код давхар бүрт давтагддаг (`Б1-1` нь B1 ба 01 давхарт).

## Дүрэм

**Байр** (`mapInventoryRows`, Админ → Импорт ба скриптэд адил):
- Блокийн багана, сонгосон блок байхгүй бол кодын «Б<тоо>-» угтвараас (Б1-1 → Б1). Бусад кодоос таахгүй.
- 2-оос олон орон: хөвөгч таслалын үлдэгдэл бол 2 орон руу, жинхэнэ 3 дахь орон (80.125) бол алдаа.
- Ээлж/ангилал/код давтагдвал: давхрууд нь өөр бол `Б1-1 (B1)`, `Б1-1 (01)`; давхар ижил боловч загвар өөр бол `Б1-46 (H-1)`, `Б1-46 (H-2)` (ERP-ийн түлхүүр = төрөл + загвар + код). Аль нь ч ялгахгүй бол давхардлын алдаа.

**Гэрээ** (`lib/erp/product-contracts.ts`):
- «Гэрээ баталгаажсан» (sold) ба «Хүлээлгэсэн» (handed_over) нэгж = гэрээ — Хурлын бэлтгэлийн «Гэрээтэй» + «Бартер»-тай ижил. «Захиалга үүссэн», «Хадгалсан» гэрээ биш.
- `unit_label` = байрны код; нийт үнэ, гэрээлсэн талбай, урьдчилгааны нөхцөл/дүн, суваг, менежер (ERP-ийн нэрээр), захиалагч (регистрийг тусад нь) ERP-ээс.
- 1м²-ийн үнэ: талбай × үнэ нийт дүнтэй (1%) таарахгүй бол хадгалахгүй (зогсоолд ERP нэгжийн үнийг бичдэг).
- Захиалгын төлөв `closed` → «Хаагдсан», бусад нь идэвхтэй.
- Экспортод **гэрээний дугаар, огноо, төлсөн дүн байхгүй**: NULL. «Үлдэгдэл төлбөр» нь нийт − урьдчилгаа (хуваарь), харилцагчийн өр биш тул хадгалахгүй.

**Төлсөн дүн тодорхойгүй гэрээ:** жагсаалт, дэлгэрэнгүйд «—» (0₮ биш), статистик `unknown_paid`-ыг тоолно. `PaymentService.addPayment` ийм гэрээнд 409 буцаана: RPC NULL-ийг 0 гэж үзэж үлдэгдлийг буруу бодох тул төлсөн дүнтэй гэрээний экспорт орох хүртэл төлбөр бүртгэхгүй. Огноогүй тул сарын KPI, долоо хоногийн тайланд гэрээний огноогоор тоологдохгүй (тайлан ERP snapshot-оос хэвээр).

## Ажиллуулах

```bash
SHOP_ID=6bdbef70-38e1-4513-933e-a503575e3875 npx tsx scripts/import-erp-snapshot.ts          # шалгах (бичихгүй)
SHOP_ID=6bdbef70-38e1-4513-933e-a503575e3875 npx tsx scripts/import-erp-snapshot.ts --apply  # бичих
```

Сүүлийн бүтээгдэхүүний snapshot-ыг уншина. Зөвхөн шинэ байр, гэрээ нэмнэ (дахин ажиллуулахад давхардахгүй, бүртгэлтэйг өөрчлөхгүй); нэг мөр алдаатай бол юу ч бичихгүй. `admin_audit_log`-д `erp.snapshot_import`.

## Мэдэгдэж буй зүйл

- ERP-ийн өгөгдлийн алдаа: Excel-ийн 365-р мөр «Б1-46» агуулах H-2 нь 01 давхар гэж бичигдсэн (бусад H-2 бүгд B1). Загвараар ялгасан.
- 4 гэрээний «Захиалагч» нь зөвхөн утасны дугаар; хэдэн нэрийн ард утас/ХХК-ийн регистр бий — ERP-д байгаагаар хадгална.
- Дараагийн ERP файлаар байрны төлөв шинэчлэгдэхгүй (импорт зөвхөн шинэ мөр нэмнэ); Хурлын бэлтгэл ERP-ээс шууд уншсаар.
- Гэрээний менежерийн нэр ERP-ийнх («Чанцалдулам.Раднаа»); Elysium-ийн бүртгэлд «Чанцалдулам» — хувийн KPI-д таарахын тулд бүртгэлийн нэрийг ERP-тэй ижил болгоно.
