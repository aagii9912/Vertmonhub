# Vertmon Hub · Дизайн систем v3 «Шөнө»

**Төлөв:** 1-р шат (суурь) хийгдсэн — токен, фонт, бараан үндсэн тема, shell, үндсэн компонент, брэнд тэмдэг. Хуудас бүрийн шинэ загвар 2–9-р шатанд.
**Шийдвэр (2026-10-05):** эзэмшигч UI v3 төлөвлөгөөний **Б · Шөнө** чиглэлийг сонгосон; гар утасны тусгай UI хэрэггүй, зөвхөн веб (desktop, 1280–1920px).
**Төлөвлөгөө:** аудит, 3 чиглэл, 10 үе шат — [UI v3 төлөвлөгөө](https://claude.ai/artifact/QnRjVUmVb2RnnwjACEVoLc) (хувийн холбоос).

## Зарчим

1. Дараагийн ажил эхэнд; тайлбар, тойм араас нь.
2. Нэг хүн, нэг карт (лид, харилцагч, мессеж, уулзалт, гэрээ, төлбөр нэг түүхэнд).
3. Тоо үнэн байна: мэдээлэлгүй бол «—» ба шалтгаан, алдаа хэзээ ч хоосон жагсаалт биш.
4. Цөөн загвар (8 хуудасны загвар, ~35 компонент), lint-ээр хамгаална.
5. Тайван интерфэйс: өнгө зөвхөн утга илэрхийлнэ, нэг accent, сүүдрийн оронд хүрээ.
6. Үнэтэй мэдрэмж нарийвчлалаас: тэгш зай, хэмнэлтэй үсэг, нэг дэлгэцэнд нэг гол зүйл.

## Тема

- **Бараан (үндсэн).** `:root` дээр. `layout.tsx`-ийн эхний script `localStorage['vh-theme'] === 'light'` биш бол `data-theme="dark"` тавина.
- **Цайвар.** `:root[data-theme="light"]`; хэрэглэгчийн цэс → «Цайвар тема» (`useTheme`).
- **Sidebar** хоёр темд ч бараан (`--sidebar-*`), контентын токентой холилдохгүй.
- **Хэвлэх** (`.weekly-report`) үргэлж цайвар.

## Дүрэм

- Текстэд `text-brand` бус `text-brand-strong`; hover дэвсгэрт `hover:bg-brand-hover`.
- Хатуу төлөвийн дэвсгэр дээр `text-background` (бараанд бараан, цайваранд цагаан текст); устгах товч `bg-destructive` (= `danger-solid`).
- Input, select, checkbox, switch: `border-control`.
- Focus: base layer-ийн 2px outline ганцаараа; компонентод `focus-visible:ring-*` нэмэхгүй (`.focus-ring` нийцтэй үлдсэн).
- Хамгийн жижиг текст 12px (`text-2xs` = 12px болсон). Кирилл үгэнд mono фонт хэрэглэхгүй.
- Фонт: Inter (latin, cyrillic, cyrillic-ext — Ө, Ү, ₮ бүгд бий; Golos Text-д ₮ байгаагүй).
- Брэнд тэмдэг: `components/brand/BrandMark` (Vertmon blue дөрвөлжин, цагаан «V»); favicon, `public/icon.svg`, PWA icon (maskable, iOS) ижил.

## Shell ба навигаци (2-р шат)

- **Ганц бүртгэл** — `src/lib/navigation/nav.ts`: `NAV_SECTIONS` (Өнөөдөр · Борлуулалт · Үр дүн · super_admin-ийн «Удирдлага»), `BOTTOM_NAV` (Тохиргоо), `SECONDARY_ROUTES` (зөвхөн ⌘K). Sidebar, ⌘K, замын мөр, браузерын табын гарчиг (`getDocumentTitle`), шууд URL-ийн эрх (`getRouteModule`, `isSuperAdminRoute`) бүгд эндээс. Шинэ хуудас нэмэхэд энд бүртгэнэ.
- **Нэр томьёо** — Мессеж (Inbox биш), Шатаар (Pipeline биш), Өгөөж (ROI), Имэйл товхимол, Өнөөдөр / Самбар (хувийн / байгууллагын горим).
- **Sidebar** — 232px, хумисан 64px icon rail (`<html data-sidebar="collapsed">`, layout-ийн script будахаас өмнө тавина). Зөвхөн навигаци; «Удирдлага» админ хуудсан дээр нээлттэй, бусад үед хумигдана.
- **Дээд мөр (56px)** — зүүн: төсөл / хэсэг / хуудас; баруун: хайлт ⌘K, «+ Шинэ» (лид, уулзалт, ажил — эрхтэйг л), мессеж, AI ⌘J, тусламж, профайл (тема, товчлол, гарах).
- **⌘K** — хуудас, үйлдэл, бичлэг (лид, гэрээ); бичлэгийг байгаа жагсаалтын API-аар (эрх, `applyLeadScope` серверт) хайна, нэргүй лид `leadDisplayName`-ээр.
- **Товчлол** — `?` жагсаалт, `G → D/L/V/C/M/R/S` шилжилт, `N` шинэ лид, ⌘K, ⌘J; физик товчоор (`KeyboardEvent.code`) таньдаг тул кирилл байрлалд ч ажиллана.
- **Зөвхөн веб** — sidebar үргэлж харагдана, ажлын хэсгийн хамгийн бага өргөн 1024px; гар утасны доод таб, «+», mobile карт, PWA суулгах санал хасагдсан. Нийтийн хуудсууд (нүүр, /contact, хууль зүй, нэвтрэх) responsive хэвээр.
- **404** — нийтийн монгол 404 (`app/not-found.tsx`), shell доторх 404 (`/dashboard/*`, `/marketing/*`-ийн танигдаагүй зам).

## Лид ба Харилцагчийн карт (3a-р шат)

- **Лид** (`/dashboard/leads`, `components/leads/LeadsPage.tsx`) — гарчиг «Лид» (төсөл · идэвхтэй тоо), нэг үндсэн товч «Лид нэмэх». Анхаарах 4 тоо (Хариуцагчгүй, Холбоо бүртгээгүй, Дараагийн алхамгүй, Хугацаа хэтэрсэн) нь шүүлтүүр (`?queue=`, дахин дарвал арилна). Харагдац (Бүгд, Миний, Шинэ, Уулзалттай, Идэвхтэй) тоотойгоо; «Харагдац хадгалах» нь одоогийн шүүлтүүрийг нэрлэж энэ төхөөрөмжид хадгална.
- **URL** — шүүлтүүр, эрэмбэ, хуудас URL-д (`lib/leads/list-params.ts`); анхдагч үед `/dashboard/leads` цэвэр. Сонгосон лид `?lead=`.
- **Жагсаалт ↔ Шатаар** — `LeadsViewSwitch`; шүүлтүүр хоёр талд хадгалагдана. «Шатаар» самбарын картыг дарахад (эсвэл Enter) карт нээгдэнэ, Space-ээр гараар чирнэ.
- **Гараар** — ↑/↓ дараагийн лид (карт дагана), Enter нээх, Esc хаах.
- **Дараагийн алхам** — `lib/leads/next-step.ts`: жагсаалт, карт, Өнөөдөр нэг дүрмээр; хоцролт `work-queue`-тэй ижил (товлосон цаг өнгөрмөгц), өдөр Улаанбаатарын хуанлиар; «Маргааш / 3 хоног / 7 хоног» нь УБ-ийн 10:00.
- **Харилцагчийн карт** (`components/leads/LeadCard.tsx`) — жагсаалтын хажууд (1280px-ээс доош давхарлана) ба `/dashboard/leads/[id]` бүтэн хуудас. Толгой (нэр inline засвар), төлөв, «Залгах», «Уулзалт товлох», ⋯; «Дараагийн алхам» хайрцаг — «Дууссан» нь үр дүн + дараагийн алхмыг нэг дор асууна (алхам сонгоогүй бол хуучныг цэвэрлэж «Дараагийн алхамгүй» болгоно; уулзалтын алхам бол уулзалтыг «болсон» гэж тэмдэглэнэ). Табууд: Тойм (баримт + сүүлийн үйл явдал: түүх, мессеж, санал гомдол нэг урсгалд), Түүх (менежерүүдийн түүх), Мессеж (24 цагийн цонх, Мессеж рүү), Гэрээ (лидийн + ижил утастай; төлсөн дүн тодорхойгүй бол «—»), Санал гомдол.
- **Картын өгөгдөл** — `GET /api/dashboard/leads/[id]/customer` (`lib/leads/customer-card-load.ts`): лидийг `applyLeadScope`-оор уншаад нормчилсон утсаар харилцагч, мессеж, гэрээ, санал гомдлыг олно; эрхгүй модулийн хэсэг огт уншигдахгүй, уналт `partial`-д нэрээрээ. Хүснэгт, merge дүрэм хэвээр (зөвхөн UI нэгдэв).
