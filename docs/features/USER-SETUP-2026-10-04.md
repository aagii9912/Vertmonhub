## 1. Админы жагсаалт: шинэ борлуулалтын менежер

Жишээ нь энэ удаагийн хэрэглэгч. Super Admin https://www.vertmon.mn дээр гүйцэтгэнэ.

**0. Урьдчилан тодруулах (эзэмшигчээс):**
- Бодит бүтэн нэр, кирилл үсгээр. ERP-ийн «Борлуулалтын менежер» баганын бичлэгтэй яг ижил байна (жишээ нь «Ариунбилэг.Нямхүү» хэлбэр). Weekly тайлан, KPI гэрээ, лидийг энэ нэрээр танина.
- Аль төсөлд ажиллах: Mandala Garden, Mandala 360&365 Tower, Elysium Residence. Энэ хэрэглэгчийн хувьд **эзэмшигч баталгаажуулна**. Имэйлийн moncon.mn домэйноос төслийг таахгүй.
- Дүр: «Борлуулалтын менежер». Зөвхөн өөрт хуваарилсан лид, бүртгэлтэй төслүүдээ харна.

Нэр, төсөл батлагдаагүй бол акаунтыг үүсгэхгүй. Идэвхтэй менежерийн нэрийг дараа нь «Засах»-аар солих боломжгүй (§2).

**1. Шалгах:**
- Админ → Дүрүүд: «Борлуулалтын менежер» дүрд Хянах самбар, Лид, Уулзалт, Харилцагч, Гэрээ, Inbox, Тайлан, Лидийн тайлан, AI туслах модулиуд идэвхтэй.
- Админ → Борлуулалтын төлөвлөгөө → тухайн төсөл: «Идэвхтэй менежерүүд» болон «Идэвхгүй менежерүүдийг харах» дотор ижил нэр байгаа эсэх.
  - ERP-ээс ирсэн, акаунтгүй ижил нэр байвал яг тэр бичлэгээр бичнэ. Систем тэр мөрийг энэ акаунтад холбоно.
  - Өөр хүний нэр бол нэрийг ялгаж бичнэ. Ижил нэрийг авбал тэр хүний лид, KPI шилжинэ.
- Админ → Хэрэглэгчид: «Хайх…» талбарт `chantsaldulam` гэж бичиж өмнө нь бүртгэл байгаа эсэхийг шалгана.

**3. Жагсаалтын мөрийг шалгах:**
- Дүр = Борлуулалтын менежер;

- «Идэвхтэй менежерийн холбоосгүй» / «Зарим төсөлд менежерээр бүртгэгдээгүй» шар анхааруулга **гарахгүй**.

**4. Нэмэлт төсөл:** мөрийн «Төслүүд» → төслүүдийг чагтлах → «Хадгалах». Төсөл бүрт гишүүнчлэл, менежерийн бүртгэл, төслийн харьяалал нэг дор үүснэ. Борлуулалтын төлөвлөгөө хэсэгт нэмэлт хадгалалт шаардахгүй. Төсөл бүрт нэр «Идэвхтэй … · акаунттай» гэж харагдана.

**5. Нэвтрэх мэдээлэл дамжуулах:** https://www.vertmon.mn/auth/login, имэйл, түр нууц үгийг 88883375 дугаараар утсаар эсвэл SMS-ээр өгнө. **Нууц үгийг имэйлээр бүү илгээ.** Хэрэглэгч нууц үгээ өөрөө солих, сэргээх боломж одоогоор алга. Шаардлагатай бол админ мөрийн «Нууц үг» товчоор шинэчилнэ.

**6. Баталгаажуулалт:**
- нэвтрэхэд /dashboard «Өнөөдөр» горим нээгдэнэ;
- Лид хэсэгт зөвхөн өөрт хуваарилсан лид харагдана;
- толгойн «Төсөл» цэсээр төсөл солигдоно;
- админы жагсаалтад «Нэвтэрсэн» төлөв гарна.

Шаардлагатай бол админ Лид хэсэгт тухайн төслийн лидийг түүнд хуваарилна.

**Нэр буруу бичигдсэн бол:** идэвхтэй менежерийн нэрийг «Засах»-аар солихгүй (409).
1. Борлуулалтын төлөвлөгөө → холбогдсон төсөл бүрт тухайн мөрийн «Акаунтын холбоос салгах».
2. Хэрэглэгчид → «Засах» → зөв нэр.
3. «Дүр солих» (Борлуулалтын менежер + төсөл) эсвэл «Төслүүд»-ээр дахин холбоно.
4. Буруу нэртэй хуучин мөрийг Борлуулалтын төлөвлөгөө хэсэгт идэвхгүй болгоно.

## 3. Дүрэм

- Утас нь хувийн мэдээлэл. Зөвхөн super_admin-ийн API (`GET /api/admin/users`, профайл засах) уншина. `admin_audit_log`-д утгыг нь бичихгүй. AI-аар урихад бусад AI бичих үйлдлийн адил tool-ийн args (утас орно) `ai_audit_log`-д үлдэнэ. `user_profiles`-ийн хуучин self RLS хэвээр. Бусад API (`/api/dashboard/team` г.м.) утас сонгодоггүй.
- Утас заавал биш. Хоосон бол null. Буруу утга (8 оронгүй, үсэгтэй) 400 өгнө. Чимээгүй хаягдахгүй.
- Борлуулалтын менежерийн нэрийн дүрэм нэмэх, урих, AI урих, профайл засах, provisioning бүгдэд нэг (`managerNameMissing`). Имэйлтэй ижил нэр (том, жижиг үсэг үл хамааран) бодит нэр биш.
- Бүртгэлтэй акаунтыг урихад профайлын нэр хүчинтэй. Бичсэн нэр, утас профайлыг дарж бичихгүй. Засварыг «Засах»-аар хийнэ.

## 4. Production-д оруулах дараалал

1. Уншилтын шалгалт:
   ```sql
   SELECT column_name FROM information_schema.columns
    WHERE table_schema = 'public' AND table_name = 'user_profiles' AND column_name = 'phone';
   SELECT count(*) FROM public.user_profiles WHERE phone IS NOT NULL;
   ```
   Багана 002-оос хойш байх ёстой, код бичдэггүй байсан тул утга нь бүгд NULL байх төлөвтэй.
2. Migration `20261004165000_user_profile_phone.sql`-ийг оруулна (node + `pg`, нэг гүйлгээ, `supabase_migrations.schema_migrations`-д бүртгэнэ).
3. Дараа нь кодыг deploy хийнэ. `GET /api/admin/users` `phone` сонгодог. Багана байхгүй бол хэрэглэгчдийн жагсаалт алдаа өгнө.
