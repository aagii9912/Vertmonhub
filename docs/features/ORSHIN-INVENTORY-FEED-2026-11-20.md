# Orshin 3D-д байрны төлөв өгөх — 2026-11-20

Статус: салбар `feat/orshin-inventory-feed` (main-д ороогүй, production-д тохируулаагүй).

## Зорилго

Elysium Residence-ийн 3D аялал, киоск (Orshin 3D, тусдаа репо) айлын төлөвийг (чөлөөтэй / захиалсан / зарагдсан)
санамсаргүй жишээ өгөгдлөөр биш Hub-ийн бүртгэлээс харуулна. Orshin 3D минут тутам уншина (өөрийн серверээс, 60 с кэштэй).

## Endpoint

`GET /api/integrations/orshin/inventory` — сервер хооронд, `Authorization: Bearer <ORSHIN_INVENTORY_SECRET>`.

```json
{
  "project": "Elysium Residence",
  "asOf": "2026-11-13",
  "source": "contracts",
  "units": [{ "code": "Б1-53", "kind": "residential", "block": "Б1", "floor": 12, "model": "E5", "status": "sold" }]
}
```

- Төлөв нь Лхагвын тайлан, AI `list_properties`-тэй **нэг дүрэм** (`loadReportInventory`): HUB гэрээний жагсаалт ERP
  экспортоос шинэ бол байрны бүртгэл дээр амьд гэрээг давхарлана, үгүй бол ERP экспорт, эс бөгөөс бүртгэл. `source`,
  `asOf` нь тэр эх сурвалж ба огноо. `status` ∈ available | reserved | ordered | sold | handed_over | null.
- Хариунд **үнэ, талбай, менежер, худалдан авагч, бартер, дотоод төлөвийн тайлбар байхгүй** — талбарын жагсаалт
  `lib/inventory/public-feed.ts`-д ил; мөрийг бүхлээр нь дамжуулахгүй (тест баталгаажуулна).
- Бүх ангилал (орон сууц, зогсоол, агуулах, үйлчилгээ) нэг жагсаалтад, `kind`-аар ялгана. Код ангилал дамжин давтагддаг.
- Тохируулаагүй → 503; токен буруу → 401; төсөл олдохгүй эсвэл байр бүртгэгдээгүй → 503 (хоосон жагсаалт буцаахгүй —
  хүлээн авагч «бүгд худалдаанд гараагүй» гэж уншихаас сэргийлнэ); уншилтын алдаа → 500. `Cache-Control: private, no-store`.
- `route-auth-guard`-ын нийтийн жагсаалтад бүртгэсэн (өөрийн Bearer токен, `safeEqual`). Бичих үйлдэл байхгүй.

## Тохиргоо (Vercel, production)

| Хувьсагч | Утга |
|---|---|
| `ORSHIN_INVENTORY_SECRET` | `openssl rand -base64 48`; Orshin 3D-ийн `INVENTORY_SECRET`-тэй ижил |
| `ORSHIN_INVENTORY_PROJECT_ID` | Elysium Residence-ийн `projects.id` (Админ → Төслүүд) |

Orshin 3D тал: `INVENTORY_URL=https://www.vertmon.mn/api/integrations/orshin/inventory`, `INVENTORY_SECRET`.

## Orshin 3D дахь тохируулга (мэдээлэл)

Код → 3D-ийн айл: блок + давхар + загвараар (`src/project/crm.ts`, Orshin 3D репо). Б1: E3…E7 (2-р давхарт E1, E2)
давхрын 5 байрлалтай нэг нэгээр таарна. Б2 давхартаа 6 айлтай (A–F) боловч 3D загвар одоогоор Б1-ийн 5 айлын
хуваалтыг ашигладаг тул C, D, E л таарна; A, B, F-ийг харуулахын тулд Б2-ын давхрын зураг хэрэгтэй. Зогсоолын 3D
схем жишээ тул зогсоолын төлөв холбогдоогүй.

## Мэдэгдэж буй зүйл

- Нэг төсөл (нэг нууц түлхүүр). Өөр төсөл (Мандала) холбох бол төсөл бүрийн түлхүүртэй болгож өргөтгөнө.
- Төлөвийн шинэчлэл Hub-ийн импортоос хамаарна: ERP файл, HUB гэрээний жагсаалт орох хүртэл 3D дээрх төлөв өмнөх хэвээр.
