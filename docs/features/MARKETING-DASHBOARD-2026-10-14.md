# Маркетингийн самбар (2026-10-14)

Статус: main-д орсон 2026-10-15 (production, www.vertmon.mn). Миграци шаардлагагүй.

## Яагаад

Борлуулалтын менежер `/dashboard` дээр өөрийн «Өнөөдөр»-ийг (уулзалт, залгах лид, сарын зорилт) хардаг.
Маркетингийн менежер (`marketing` дүр) өмнө нь захирлын борлуулалтын самбар руу ордог байсан. Эзний шийдвэр
(2026-10-13): маркетинг зөвхөн контент бүтээж, өөрийн төлөвлөгөөгөөр ажилладаг — лид, гэрээ, борлуулалтын
хөрвөлтөөр хэмжихгүй, тайлан нь борлуулалтаас тусдаа.

## Хэн юу харах вэ

`GET /api/dashboard/mode` (сервер шийднэ, `mode` өөрчлөгдөөгүй):

| Хэрэглэгч | `/dashboard` |
|---|---|
| Борлуулалтын менежер (`personal`) | «Өнөөдөр» — өөрчлөгдөөгүй |
| `marketing` дүр, админ биш, менежерийн бүртгэлгүй (`marketingHome`) | Маркетингийн самбар |
| `marketing-roi` эрхтэй бусад (админ, super_admin) (`canViewMarketing`) | Захирлын самбар; толгойн «Борлуулалт / Маркетинг» табаар `?view=marketing` |

Маркетинг дүртэй хэрэглэгч борлуулалтын менежерийн бүртгэлд холбогдсон бол «Өнөөдөр» хэвээр (personal түрүүлнэ).

## Самбарын хэсгүүд

Бүгд одоо байгаа API-аар, шинэ хүснэгтгүй:

- **Өнөөдрийн контент** — `content_calendar`: сүүлийн 30 хоногийн хоцорсон (нийтлээгүй) контент ба өнөөдрийн контент.
  Мөр бүр дээр «Нийтэлсэн» (`status: published`), «Маргааш» (`scheduledDate` +1) — `PATCH /api/marketing/content-plan/[id]`
  (marketing-roi бичих эрх). Мөр дээр дарахад контентын цонх (постер, хариуцагч, тайлбар).
- **Ирэх 7 хоног** — өдөр бүрийн контент, контентгүй өдрийн тоо; «+» тухайн өдрийн огноотой шинэ контент.
- **Сарын контент төлөвлөгөө** — нийтэлсэн / төлөвлөсөн, %, нийтлэх үлдсэн, хоцорсон, цуцалсан, төрлөөр задаргаа
  (`summarizeContentPlan`, цуцалсныг төлөвлөгөөнд тооцохгүй).
- **Facebook хуудас** — хурлын долоо хоногийн (Лхагва–Мягмар) хадгалсан органик үзүүлэлт
  (`/api/dashboard/marketing/social-week`, Лхагвагийн слайдтай ижил дүрэм); хуудас холбоогүй бол тайлбар.
- **Сарын төсөв** — `/api/marketing/budget`-ийн тухайн сарын төсөв ба зарцуулалт (ханшгүй Meta мөр нийтэд орохгүй).

Нэг уншилт: `marketingHomeWindow` = min(сарын эхэн, өнөөдөр−30) … max(сарын сүүл, өнөөдөр+7) (≤ 93 өдөр, API-ийн хязгаар).
Өдөр нь Улаанбаатарын өдөр (`ubDateStr`). Логик: `src/lib/marketing/marketing-home.ts`; UI:
`src/components/dashboard/marketing/MarketingDashboard.tsx`; толгойн текст/таб: `WorkspaceIntro` (`variant="marketing"`).
