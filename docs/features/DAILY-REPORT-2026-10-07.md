# Өдрийн тайлан (Mandala Garden, Elysium багийн загвар)

Огноо: 2026-10-07 (Улаанбаатар). Салбар: `feat/daily-report`. Эх сурвалж: эзэмшигчийн илгээсэн 2026.09.30-ны «МАНДАЛА ГАРДЕН БАГ», «"ЭЛИЗИУМ РЕСИДЕНС" БАГ» өдрийн тайлангийн зураг.

**Төлөв:** код, unit/SQL/route/e2e тест бэлэн. Migration `20261007120000_daily_reports.sql` production-д **ороогүй** — deploy-оос **өмнө** хэрэглэнэ (эс бөгөөс хуудас, API 503 «идэвхжээгүй» гэж хариулна). Төслүүдийн загварыг (шугам, чат, менежерийн товчлол) тохируулаагүй бол анхдагч загвар харагдана.

## Цаасан тайлан → систем

| Тайлангийн хэсэг | Эх сурвалж |
|---|---|
| Утасны шугам бүрийн ирсэн дуудлага (7575-8000, ****-7711, 7786-2222, 8888/9008), менежерээр; Elysium-д Шинэ / Захиалагч, давтан / Бусад | Менежер өдөр бүр **тоогоор** оруулна (`daily_report_counts`). CallPro-гийн экспорт менежерээр задрахгүй, хотын дугаарын ихэнх дуудлага лид болдоггүй тул CRM-ийн лидийн дуудлагаас (`lead_activities`) гаргахгүй. |
| Чат (Пэйж FB, Хувь чат), менежерээр | Мөн менежерийн оруулсан тоо. Inbox-ийн чат prod-д хоосон (2026-10-07) тул автоматаар тоолохгүй. |
| Уулзалт: Шинэ / Давтан / Захиалагч, менежерээр + жагсаалт (харилцагч, тоот, нөхцөл) | **Автоматаар:** `property_viewings` `completed`, устгаагүй, уулзалтын УБ өдрөөр (`scheduled_at`), `sales_manager_name`-ээр — менежерийн KPI-тай ижил дүрэм. Мөрийн текст = харилцагчийн нэр (`leadDisplayName`) — байр, `agent_notes`, `customer_feedback`. «Товлосон» хэвээр уулзалт тайланд орохгүй, тоог нь анхааруулгаар харуулна. |
| Шугамын тайлбар («Төслийн ерөнхий мэдээлэл авсан»), нэмэлт тэмдэглэл | Багийн эрхтэй хэрэглэгч бичнэ (`daily_reports.notes`). |
| «Тайлан хийж гүйцэтгэсэн: М. Хонгорзул» | «Баталгаажуулах» дарсан хүний нэр (бүртгэлийн нэр «Р. Чанцалдулам» хэлбэрээр, эс бөгөөс профайлын нэр). |

Оруулаагүй нүд хоосон (`null`) — 0 биш; 0-ийг оруулбал «оруулсан» гэж тооцно. Тоо оруулаагүй идэвхтэй менежерийг багийн харагдацад анхааруулна.

## Загвар (төсөл бүрт)

«Өдрийн тайлан» → «Загвар» (Тохиргоо бичих эрх). `daily_report_settings.config`:

- `title` — «Мандала Гарден баг» (хоосон бол «<төсөл> баг»).
- `lines[]` — `{ key, label, categories }`; `categories` хоосон = менежер бүр нийт тоо (Mandala), эс бөгөөс `new | repeat | other` (Elysium). ≤ 6.
- `chats[]` — `{ key, label }`. ≤ 4.
- `managers` — `null` = идэвхтэй бүх менежер нэрийн дарааллаар; эсвэл `{ name, short }[]` (идэвхтэй бүртгэлийн нэр, товчлол ≤ 6 тэмдэгт, давхардахгүй).

Үзүүлэлтийн түлхүүр `call.<шугам>.<total|new|repeat|other>`, `chat.<суваг>` (DB CHECK). Шугамын нэрийг солиход хадгалсан тоо хэвээр (түлхүүрээр); шугам/ангиллыг хасвал хуучин тоо DB-д үлдэж тайланд харагдахгүй.

## Эрх

Дүрэм нь менежерийн идэвхийн тайлантай ижил (`resolveReportViewer`):

- **Менежер (хувийн горим)** — зөвхөн өөрийн багана, өөрийн уулзалт; тоогоо оруулна (`dashboard` бичих эрх). Тэмдэглэл, баталгаажуулалт, бусдын тоо харагдахгүй/засагдахгүй. Акаунттай холбосон идэвхтэй бүртгэлгүй бол «бүртгэлд холбогдоогүй».
- **Багийн харагдац** — super_admin эсвэл `reports` модультай, хувийн горимгүй хэрэглэгч: бүх менежер, тэмдэглэл, баталгаажуулалт; `dashboard` бичих эрхтэй бол бүх менежерийн тоог засна (бүртгэлийн нэр шалгана).
- Зөвхөн `dashboard`-тай байгууллагын хэрэглэгч — 403.
- Анхаар: бүртгэлд холбогдсон админ биш хэрэглэгч (жишээ нь Elysium-ийн Khongoroo, `sales_manager`) багийн тайланг харахгүй. Багийн тайланг хэн нэгтгэх нь эзэмшигчийн шийдвэр (админ эрх эсвэл менежерийн бүртгэлгүй `reports` эрхтэй хэрэглэгч).

## Хаана

- Хуудас `/dashboard/daily-report` (цэс: Үр дүн → «Өдрийн тайлан», модуль `dashboard`): өдөр сонгох, «Тоогоо оруулах»/«Засах», «Хуулах» (мессенжерийн текст), «PDF / хэвлэх» (А4, цагаан цаас), «Баталгаажуулах», «Загвар».
- API: `GET /api/dashboard/daily-report?date=`, `PUT /api/dashboard/daily-report` `{ date, cells: [{ manager, metric, value|null }], notes?, complete? }`, `PUT /api/dashboard/daily-report/settings` `{ config }`. Ирээдүйн өдөр 400; загварт байхгүй үзүүлэлт 409 («хуудсаа шинэчил»).
- AI: `get_daily_report` (унших, `reports`|`dashboard`, төслийн хүрээтэй) — «өнөөдрийн/өчигдрийн өдрийн тайлан», `plainText` нь хуулахад бэлэн.
- Код: `lib/dashboard/daily-report.ts` (цэвэр: загвар, тайлан, текст), `lib/dashboard/daily-report-load.ts` (DB), `components/daily-report/*`.
