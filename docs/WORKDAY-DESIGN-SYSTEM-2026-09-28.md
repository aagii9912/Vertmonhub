# Vertmon Hub · Workday

Менежерийн өдөр тутмын ажил, Лхагва гарагийн борлуулалт ба маркетингийн хуралд зориулсан UI/UX системийн эхний хувилбар.

## Үндсэн урсгал

1. **Өнөөдөр** (`/dashboard`): өнөөдрийн холбоо, уулзалт, хувийн ажил; сарын зорилт; шинэ лид. Ажил дуусгах, хойшлуулах, залгах үйлдлүүд одоогийн API-г ашиглана.
2. **Хурлын бэлтгэл** (`/dashboard/weekly`): өмнөх Лхагвагаас Мягмар дуусталх тоог нэгтгэж, хийсэн ажил / саад / дараагийн алхам нэмнэ. Дууссан хувийн ажлаа сонгон шинэчлэлд оруулж болно.
3. **Танилцуулах**: хадгалсан шинэчлэл, борлуулалт, маркетингийн үзүүлэлтийг бүтэн дэлгэцээр харуулах, текст хуулах, браузерын PDF / хэвлэх үйлдэл.
4. **AI туслах**: өргөн бичих талбар, саармаг харилцан яриа, ажлын контекст, хадгалсан яриа. Хурлын дүгнэлт бэлдэх товч нь харагдаж буй өгөгдлийг асуултад оруулна. Одоо байгаа streaming, үйлдэл батлах, алдаа/тасалдлын төлөвийг хадгалсан.

## Дахин ашиглах бүрэлдэхүүн

- `WorkspaceIntro`: өдрийн эхлэл, AI оролт, дараагийн хурлын товч зам.
- `PageHeader`: агуулгын гарчиг + тайлбар + үйлдэл. Shell-ийн толгой замын мөрийг харуулна.
- `Panel`: нэг хүрээ, нэг толгой, доторх ажлын мөрүүд.
- `AiComposer`, `AiChat`: хажуугийн туслах болон бүтэн хуудас ижил компоненттой.
- `weekly-review.ts`: хурлын огноо, хугацаа, текст экспортын нэг эх сурвалж.
- `FilterBar`, `FilterChip`: хайлт, нэг мөрөөр гүйлгэх mobile шүүлтүүр, цэвэрлэх үйлдэл, keyboard focus.
- `StatBar`, `StatTile`, `SectionCard`: тайлан болон ажлын жагсаалтын ижил тоон тойм, хэсгийн гарчиг, зай.

## CRM ба маркетингийн үргэлжлэл

- **Лид:** гол гарчиг, шинэ лид / pipeline / Excel үйлдлүүд mobile-д ил харагдана. Анхаарах дөрвөн ангилал, хайлт, шүүлтүүр цэвэрлэх, хүснэгт ба хажуугийн самбар. Хугацаа хэтэрсэн дарааллыг эрт огнооноос харуулна. Mobile мөрөнд дараагийн алхмыг нэмсэн.
- **Уулзалт:** өдөр бүрийн бүлэг, цаг, харилцагч, байр, явц. Ирсэн гэж бүртгэх, залгах үйлдэл шууд харагдана; хойшлуулах, ирээгүй, цуцлах нь ижил цэсэнд desktop/mobile-д байна. Огноо ба өдрийн гарчиг Улаанбаатарын цагтай нийцнэ.
- **Гэрээ:** тоон тойм, гэрээ үүсгэх, хайлт, хоцролтын шүүлтүүр. Алдаатай хүсэлтийг хоосон жагсаалт гэж харуулахгүй; дахин оролдоно. Унших эрхтэй хүн бичих үйлдэл харахгүй.
- **Маркетинг:** нэгдсэн самбар / баг / бүртгэл гэсэн ажлын дараалал. Төслийн товч хүснэгт, сувгийн үр дүн, хурлын долоо хоногийн сонголт. Лидгүй сувгуудыг хүсвэл дэлгэнэ. Зардал татах, файл импортлох удирдлага нь Бүртгэл хэсэгт байна.
- **Excel:** лид, гэрээний «Excel · бүгд» нь бүх бүртгэлийг татна. `dashboardDownload` сонгосон байгууллагын `x-shop-id`-г дамжуулж, серверийн алдааг харуулна. Маркетингийн Excel сонгосон хугацаа, төсөлтэй хэвээр.
- **Хурлын маркетинг:** одоогийн API-ийн `{ report, projects, activities, spend }` хариунаас `report`-ийг уншина; browser fixture мөн энэ бүтцийг ашиглана.

## Өгөгдөл ба төлөв

- Борлуулалт одоогийн `/api/dashboard/reports/operations`, маркетинг `/api/marketing/performance`-оос сонгосон ижил хугацаагаар ирнэ. Дахин тооцоолдог өөр томьёо нэмээгүй.
- Гэрээний дүн, бодитоор бүртгэсэн мөнгөн орлого, маркетингийн хугацаанд үүссэн лидийн хөрвөлт тусдаа хэмжүүр. Дутуу дүн, огноо, ханшийн тайлбар үлдэнэ.
- Эх үүсвэр алдаатай бол тоог 0 болгохгүй. Тайлбартай unavailable төлөв харуулж, экспортод мөн оруулна.
- Хурлын долоо хоног хараахан дуусаагүй бол одоогоор бүртгэсэн мэдээлэл гэдгийг харуулна. Түүхэн хурлын тоо нь одоогийн бүртгэлээс дахин тооцогдоно; өөрчлөгддөггүй баталгаажсан snapshot биш.
- Ажлын явцыг `weekly_updates` хүснэгтэд долоо хоног/байгууллага/хэрэглэгчээр нэг мөр хадгална. Шинэчлэл оруулах нь хувийн task-уудыг багт автоматаар ил болгохгүй.
- Өөрийн шинэчлэлийг бичихэд `dashboard` + write эрх; бусдын шинэчлэлийг уншихад `reports` эрх шаардлагатай. Бусдын шинэчлэлийг API-аар засах боломжгүй.
- `shop_id`, `user_id`, нэрийг сервер тогтооно. Browser DB access хаалттай, API authentication/module/shop checks заавал хийнэ.
- Form-ийг хадгалж дуусахаас өмнө амжилт гэж харуулахгүй. Алдаа гарвал бичсэн текст үлдэнэ. Хадгалаагүй үед огноо солих, шинэчлэх, экспорт хийхийг хаана. Дууссан ажлаас оруулахад 4000 тэмдэгтээс хэтэрвэл чимээгүй тайрахгүй, тайлбар харуулна.

## Одоогийн хүрээ ба нэвтрүүлэх нөхцөл

Энэ хувилбар shared shell, өдөр тутмын самбар, хурлын workspace, AI, лид/уулзалт/гэрээний жагсаалт болон маркетингийн самбарыг шинэ загварт нэгтгэсэн. Бүх нарийвчилсан form, бусад модулийн хуудас бүрийг дахин зохион байгуулаагүй.

Хурлын шинэчлэл хадгалахад **`20260928150000_weekly_updates.sql`** шаардлагатай. Энэ ажлаар production migration ажиллуулаагүй. Git push нь DB schema-г автоматаар шинэчлэхгүй. Migration дутуу орчинд UI нь хэсэг хараахан идэвхжээгүйг ил харуулна.

Дараагийн хүрээ: багийн ирц/илгээх ёстой хүмүүсийн roster, баталгаажсан тайлангийн snapshot, хурлын шийдвэрийг эзэн ба хугацаатай багийн ажил болгох. Энэ хувилбар зөвхөн ирсэн шинэчлэлийг харуулна; бүх менежер тайлангаа өгсөн гэж тооцохгүй. Хувийн ажил нэмэх одоогийн үйлдэл ашиглагдана.
