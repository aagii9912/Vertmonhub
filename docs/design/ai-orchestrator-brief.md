# Design Brief — AI Orchestrator («AI Командын төв»)

> **Төлөв:** Ноорог v1 · **Огноо:** 2026-06-17 · **Эзэн:** Design
> **Хамрах хүрээ:** `src/app/dashboard/ai-assistant` хуудсыг chat-first, орчестраци ил харагддаг «AI Командын төв» болгон дахин зохиох.
> **Лавлах зураг:** Хавсралт А-д буй цэвэрхэн AI чатын empty-state дизайн (icon-rail sidebar, gradient мэндчилгээ, prompt картууд, баялаг оролтын талбар).

---

## 1. Товч тойм (TL;DR)

Vertmon Hub-ийн борлуулалт/маркетингийн менежер AI-тай ярилцаж **үл хөдлөхийн хайлт, лид, үзлэг, гэрээ, маркетинг, санхүүгийн** ажлуудыг ганц газраас гүйцэтгэдэг болно. Хуудас нь:

- **Chat-first landing** — лавлах зургийн адил цэвэрхэн «хоосон төлөв»: gradient мэндчилгээ, prompt картууд, том оролтын талбар.
- **Орчестраци ил харагдана** — асуулт илгээхэд AI аль *агент / tool*-уудыг ажиллуулж байгааг (жишээ нь «🔍 Үл хөдлөх хайлт → 3 үр дүн») амьдаар харуулна. Энэ нь «хосолсон» гэсэн сонголтын гол ялгаа.
- **Үр дүн нь баялаг карт** хэлбэрээр буудаг — байрны карт, лидийн карт, зээлийн задаргаа, график — зүгээр текст биш.
- **Vertmon brand** — лавлах зургийн ягаан gradient-ийг terracotta + warm cream өнгөнд хөрвүүлнэ.

**Бус хүрээ:** AI-ийн backend логик (`routeToAI`), tool-уудын дотоод хэрэгжилт өөрчлөгдөхгүй — энэ нь зөвхөн presentation layer ба composer-ийн дахин зохиомж.

---

## 2. Асуудал ба зорилго

### 2.1 Одоогийн байдал
`src/app/dashboard/ai-assistant/page.tsx` (≈407 мөр) нь **Дата / Ерөнхий** хоёр горимтой энгийн чат: зүүн талд яриа түүх, дунд талд bubble feed, доор оролт + санал pill-үүд. Recharts-аар график шигтгэдэг.

**Сул талууд:**
- AI юу хийж байгаа нь *харагддаггүй* — tool дуудалт «хар хайрцаг», хэрэглэгч үр дүнг л хардаг.
- Үр дүн ихэвчлэн текст — байр/лид/тооцоо бүтэцгүй буудаг.
- Эхлэх цэг сул — хоосон дэлгэц «юу асуухаа» зөвлөдөггүй.
- Композер ядуу — горим солих toggle л байгаа, хавсралт/зураг/домэйн сонголт сул.

### 2.2 Зорилго
| # | Зорилго | Хэмжүүр (амжилтын шалгуур) |
|---|---------|----------------------------|
| G1 | Эхлэх саатлыг багасгах | Empty-state дэх prompt картаар эхэлсэн session-ы хувь ↑ |
| G2 | Орчестрацийг ил болгох | Хэрэглэгч tool алхмуудыг харах боломжтой (100% session-д trace харагдана) |
| G3 | Үр дүнг үйлдэлд хөрвүүлэх | Үр дүнгийн картаас шууд үйлдэл (лид нээх, үзлэг товлох) хийсэн тоо ↑ |
| G4 | Brand нэгдмэл байдал | 100% terracotta token, ягаан/нил ягаан hardcode 0 |
| G5 | Хуудаснаас гарахгүй гүйцэтгэл | Нэг session дотор олон домэйн ажил дуусгах (хуудас солихгүйгээр) |

## 3. Хэрэглэгч ба хэрэглээний сценари

### 3.1 Зорилтот хэрэглэгч (RBAC дүрд тулгуурлав)
| Дүр | Гол хэрэгцээ |
|-----|--------------|
| **Борлуулалтын менежер** (`sales_manager`) — анхдагч | Байр хай, лид/үзлэг үүсгэ, зээл тооцоол, харилцагч удирд |
| **Маркетингийн мэргэжилтэн** (`marketing`) | ROI/кампанит ажил, лидийн нэгтгэл, сегмент |
| **Админ / эзэн** (`admin`) | Бүх домэйн + AI тохиргоо |

### 3.2 Гол сценари (Jobs-to-be-done)
1. **«2 өрөө байр 150 саяар хай»** → Үл хөдлөх агент хайлт → 3 байрны карт → «Үзлэг товлох» товч.
2. **«Энэ долоо хоногийн шинэ лид хэд вэ?»** → Лид агент → тоо + жагсаалт + funnel chart.
3. **«150 сая, 18 жил, 12%-аар зээл тооцоол»** → Зээлийн tool → сарын төлбөрийн задаргаа → «Харилцагч руу илгээх».
4. **«Маркетингийн энэ сарын ROI»** → Маркетинг агент → ROI карт/график.
5. **Зураг оруулаад «энэ ямар байр вэ?»** → Image input → байр таних/санал.
6. **«Үйлчлүүлэгч руу залгахыг хүсэв»** → Handover → менежерт push мэдэгдэл.

## 4. Дизайны концепц

> **Нэг өгүүлбэрээр:** Лавлах зургийн *цэвэр, агаартай chat-first landing*-ийг авч, түүн дээр **орчестрацийн ил тод байдал** (агент/tool-ийн амьд trace) ба **баялаг үр дүнгийн карт**-ыг Vertmon-ийн terracotta brand хэлээр нэмнэ.

### 4.1 Лавлах зураг → Vertmon хөрвүүлэлт (хамгийн чухал хүснэгт)

| Лавлах зургийн элемент | Vertmon хувилбар | Тэмдэглэл |
|------------------------|------------------|-----------|
| Зүүн нимгэн icon-rail (logo, +, search, home, folder, history) | **Яриа rail** — Шинэ яриа (＋), Хайх, Түүх. Одоо байгаа `ConversationSidebar`-ийг ашиглана | App-ийн үндсэн `Sidebar`/`Header` хэвээр — энэ rail нь AI workspace-ийн дотоод хоёрдогч нав |
| «Hi there, **John**» (ягаан нэр) | «**Сайн байна уу, {Нэр}**» — нэр **terracotta** (`--brand`) | Цаг хугацаагаар: Өглөөний/Өдрийн/Оройн мэнд |
| «What would like to know?» (нил ягаан→цэнхэр gradient) | «**Юу хийхийг хүсэж байна?**» — **terracotta→amber** gradient (`--brand` → `--status-pending`) | **Fraunces** display фонт. Ягаан/цэнхэр БИТГИЙ ашигла |
| Дэд гарчиг | «Доорх түгээмэл саналуудаас сонгох эсвэл өөрөө асуу» | `--muted` өнгө |
| 4 prompt карт (to-do, email, summarise, how AI works) | 4 **домэйнд тааруулсан** карт (доор §7.2) | Карт бүр аль агент руу чиглэхийг icon-оор илтгэнэ |
| «🔄 Refresh Prompts» | «🔄 Шинэ санал» — дүр/түүхэнд тааруулж саналыг сэлгэнэ | |
| «Ask whatever you want…» оролт | «**Юу ч асуу…**» composer | Доор §7.3 |
| «🌐 All Web ▾» dropdown | «**Бүх домэйн ▾**» — *scope/агент сонгогч* | Одоогийн «Дата/Ерөнхий» горимыг энд нэгтгэнэ |
| Add Attachment / Use Image | Хавсралт / Зураг (image input — байр таних) | `analyzeProductImageWithPlan` ашиглана |
| 0/1000 тоолуур + ягаан send | Тэмдэгтийн тоолуур + **terracotta** send товч | Gradient brand товч |

### 4.2 Гурван үндсэн дэлгэцийн төлөв
1. **Landing (empty state)** — §7.1. Лавлах зургийн агаартай байдал.
2. **Orchestrating (амьд)** — §7.4. User bubble + орчестрацийн trace ажиллаж байна.
3. **Result (хариу)** — §7.5. Trace нэг мөр болж хумигдаж, доор нь баялаг карт + дараагийн алхмын chip-үүд.

## 5. Visual design language (Vertmon token-д тулгуурлав)

> Эх сурвалж: `src/app/globals.css`. Шинэ өнгө/хэмжээ **бүү** оруул — доорх token-уудыг ашигла.

### 5.1 Өнгө
| Зориулалт | Token | Утга |
|-----------|-------|------|
| Дэвсгэр | `--bg` | `#FAFAF7` (warm cream) |
| Карт гадаргуу | `--surface` | `#FFFFFF` |
| Хоёрдогч гадаргуу | `--surface-2` / `--surface-3` | `#F4F3EE` / `#ECEAE3` |
| Хүрээ | `--border` / `--border-strong` | `#E5E3DB` / `#D4D1C7` |
| Үндсэн текст | `--fg` | `#0E0E10` |
| Бүдэг текст | `--muted` | `#6B6962` (AA 4.5:1) |
| **Brand** | `--brand` | `oklch(0.62 0.13 38)` terracotta |
| Brand зөөлөн (bg) | `--brand-soft` | `oklch(0.94 0.04 38)` |
| Brand хүчтэй (текст) | `--brand-strong` | `oklch(0.50 0.15 38)` |
| Amber (gradient төгсгөл) | `--status-pending` | `oklch(0.68 0.11 75)` |
| Амжилт / алдаа | `--status-success` / `--status-danger` | tool ✓ / ✗ төлөвт |

**Hero gradient (мэндчилгээ):**
```css
background: linear-gradient(100deg, var(--brand) 0%, var(--status-pending) 100%);
-webkit-background-clip: text; color: transparent;
```
Dark mode: `--brand` → `oklch(0.72 0.13 38)` (globals.css аль хэдийн тодруулсан).

### 5.2 Typography
| Хэрэглээ | Стек | Жишээ |
|----------|------|-------|
| Hero мэндчилгээ | `--font-display-stack` (**Fraunces**) | «Юу хийхийг хүсэж байна?» |
| Бие/UI/чат | `--font-sans-stack` (**IBM Plex Sans**) | Бүх label, bubble, карт |
| Tool/код/тоо | `--font-mono-stack` (IBM Plex Mono) | Tool нэр, тооцооны үр дүн |

Мөрийн өндөр: бие `--leading-body` (1.55), гарчиг `--leading-heading` (1.15). Tracking: `--tracking-tight` гарчигт.

### 5.3 Хэлбэр, сүүдэр, зай
- Радиус: композер/том карт `--r-3xl` (28px), үр дүнгийн карт `--r-2xl` (20px), chip `--r-md`/`--r-lg`.
- Сүүдэр: композер `--shadow-xl`, карт `--shadow-lg`, hover `--shadow-md`.
- Зай: контейнер `max-w-3xl mx-auto` (landing), хэсэг хооронд `space-y-6`, карт дотор `p-5`.

## 6. Орчестрацийн загвар (гол ялгаа)

### 6.1 Зарчим
Хэрэглэгч асуухад `routeToAI()` дотор Gemini нэг буюу хэд хэдэн tool дуудна. Энэ **дуудлагын гинжийг амьдаар, ойлгомжтой** харуулна — гэхдээ техникийн нэр биш, **хүний хэлээр**.

### 6.2 Orchestration trace компонент
Асуулт болгоны доор хумигддаг «trace» мөр:
```
● Хүсэлтийг ойлголоо
🔍 Үл хөдлөх агент · хайлт хийж байна…        ⟳
📊 Зээлийн тооцоолуур                          ✓
```
- Алхам бүр: **агентын icon** + **хүний хэлээр label** + **төлөв** (⟳ ажиллаж байна / ✓ амжилт / ✗ алдаа) + дэлгэрэнгүй (expand).
- Дууссаны дараа нэг мөр болж хумигдана: «✓ 3 алхам гүйцэтгэлээ ▾».
- `prefers-reduced-motion` үед спиннер биш статик төлөв.

### 6.3 Tool → UI зураглал (12 tool)
| Tool | Хүний label | Домэйн/Агент | Icon (lucide) | Үр дүнгийн карт |
|------|-------------|--------------|---------------|-----------------|
| `search_properties` | Үл хөдлөх хайлт | Property | `Search`/`Building2` | Байрны карт жагсаалт |
| `show_property_images` | Зураг үзүүлэх | Property | `Image` | Зургийн галерей |
| `calculate_loan` | Зээлийн тооцоо | Finance | `Calculator` | Төлбөрийн задаргаа |
| `schedule_viewing` | Үзлэг товлох | Viewings | `Calendar` | Баталгаажуулалт + .ics |
| `create_lead` | Лид үүсгэх | Leads | `UserPlus` | Лидийн карт |
| `collect_contact_info` | Холбоо барих мэдээлэл | Customers | `Phone` | Харилцагчийн карт |
| `request_human_support` | Хүн рүү шилжүүлэх | Handover | `LifeBuoy` | Push илгээсэн banner |
| `remember_preference` | Сонголт сануулах | Memory | `Bookmark` | Чимээгүй chip |
| `tag_customer_behavior` | Зан төлөв тэмдэглэх | Customers | `Tag` | Tag chip-үүд |
| `append_customer_note` | Тэмдэглэл нэмэх | Customers | `StickyNote` | Тэмдэглэлийн мөр |
| `check_payment_status` | Төлбөрийн төлөв | Finance | `CreditCard` | Төлбөрийн карт |
| `log_service_request` | Үйлчилгээний хүсэлт | Customer-service | `Ticket` | Тикетийн карт |

> RBAC: tool бүр дотор нь модуль шаардана (ж: `create_lead` → `leads`). Хэрэглэгчид эрх байхгүй бол тухайн агент/санал саарал болж, шалтгаан tooltip харагдана.

### 6.4 Scope/агент сонгогч (composer-ийн «Бүх домэйн ▾»)
Орчестраторын хайх талбарыг хязгаарлаж нарийвчлал нэмнэ:
- **Бүх домэйн** (auto-route, default)
- **Үл хөдлөх** · **Лид & харилцагч** · **Маркетинг** · **Санхүү**
- Эх сурвалж toggle (одоогийн **Дата ↔ Ерөнхий** горим) энэ menu дотор нэгдэнэ.

### 7.2 Prompt картууд (домэйнд тааруулсан, дүрээр шүүгдэнэ)
Карт бүр: дээд буланд агентын icon, 2 мөр текст, доор нь жижиг агент label.
| Карт | Текст | Чиглэх агент |
|------|-------|--------------|
| 🔍 | «2 өрөө байр 150 саяар хай» | Үл хөдлөх |
| 👥 | «Энэ долоо хоногийн шинэ лидүүд» | Лид |
| 📊 | «Энэ сарын маркетингийн ROI» | Маркетинг |
| 🧮 | «150 сая, 18 жилийн зээл тооцоол» | Санхүү |

«🔄 Шинэ санал» дарахад дүр/түүх/улирлаар өөр 4 санал гарна (ж: маркетинг дүрд маркетингийн саналууд).

### 7.3 Composer (оролтын талбар) — анатоми
- **Толгой мөр:** placeholder «Юу ч асуу…» + баруун дээд талд **scope сонгогч** «Бүх домэйн ▾».
- **Footer мөр:** зүүн талд `⊕ Хавсралт`, `🖼 Зураг`; баруун талд `тэмдэгт/1000` тоолуур + **send** (brand gradient дугуй товч, `→`).
- **Зан төлөв:** `Enter` = илгээх, `Shift+Enter` = мөр таслах; өсдөг textarea (max ~6 мөр); хоосон үед send идэвхгүй; илгээх үед спиннер.
- Mobile дээр composer доод талд бэхлэгдэж, scope сонголт BottomSheet-ээр нээгдэнэ.

### 7.4 Orchestrating төлөв
- User bubble (баруун, brand-soft дэвсгэр) гарч ирнэ.
- Доор нь §6.2 trace амьдаар бичигдэнэ (алхам алхмаар).
- Skeleton/shimmer-ийг үр дүнгийн картын байрлалд харуулна.

### 7.5 Result төлөв
- Trace → «✓ N алхам ▾» болж хумигдана.
- AI-ийн товч текст хариу (IBM Plex Sans).
- **Үр дүнгийн карт(ууд)** — §6.3-ын дагуу (байр/лид/зээл/график). Одоо байгаа `Card`, `DataTable`, Recharts ашиглана.
- **Дараагийн алхмын chip-үүд** (quick replies): ж. «📷 Зураг үзэх», «📅 Үзлэг товлох», «👤 Лид болгох».

## 8. Микро-харилцаа ба анимэйшн
- **Мэндчилгээ:** ачаалахад мөрүүд дараалан 200ms stagger fade/slide-up.
- **Prompt карт:** hover-д `--shadow-md` + 2px дээш; дарахад composer-т текст бөглөгдөж фокус орно.
- **Send:** товч brand→amber богино pulse; trace дээрээс доош «бичигдэх» эффект.
- **Trace алхам:** ⟳ эргэлдэх → ✓ check морф (200ms).
- **Карт буух:** доороос 8px slide-up + fade (150ms).
- **Reduced motion:** бүх morph/slide-г опасити шилжилтээр сольж, спиннерийг статик цэгээр орлуулна.
