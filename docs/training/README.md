# Vertmonhub ашиглах сургалт

[HTML слайдыг нээх](./vertmonhub-user-guide.html) · [PDF хувилбар](./vertmonhub-user-guide.pdf). Файлыг татаж аваад Chrome, Edge эсвэл Safari-д нээж болно. Зураг, фонт нь файлдаа багтсан тул интернэтгүй ажиллана.

22 слайд, ойролцоогоор 25 минут. Админы төсөл/акаунт/идэвхтэй менежер ба төслийн харьяаллын тохиргоо, менежерийн лид/дуудлага/уулзалт/хувийн ажил/AI/хурлын бэлтгэл, дадлагын чеклистийг хамарсан.

- **← / →**: слайд шилжүүлэх. **Home / End**: эхлэл, төгсгөл.
- **Агуулга** эсвэл **O**: хүссэн слайд руу очих.
- **Бүтэн дэлгэц** эсвэл **F**: танилцуулах горим.
- Дэлгэцийн зураг дээр дарж томруулна. **Esc**: зураг, агуулгыг хаах.
- **Багшийн тэмдэглэл**: тухайн алхмын нэмэлт тайлбар, эх сурвалж.
- **PDF / хэвлэх**: бүх 22 слайдыг хэвлэх. PDF хадгалахдаа дэвсгэр зураг/өнгө хэвлэх тохиргоог идэвхжүүлнэ.
- Дадлагын чеклистийн тэмдэглэгээ зөвхөн энэ browser-д хадгалагдана. **Шинээр эхлэх** товчоор цэвэрлэнэ.

Сургалтыг 2026-10-04-ний локал код болон зохиомол өгөгдөлтэй дэлгэцийн зурагт тулгуурлан бэлтгэв. Ашиглаж буй системийн хувилбар, эрхээс цэс болон үйлдэл хамаарна. Дадлагыг сургалтын эсвэл зөвшөөрсөн жишээ өгөгдөлтэй орчинд хийнэ.

Шинэ менежерийн акаунтыг байгууллага, идэвхтэй менежерийн жагсаалтад холбоод хариуцах төслүүдэд нь ононо. Төсөлд оноогдоогүй менежер төслийн лидийг харах, бүртгэх, хариуцах эрхгүй.
