# Docs

- `features/` — how current features behave and roll out (marketing performance, Meta spend sync/import, newsletter, operations workflow, project lead access/ingress, admin project budget, workday design system, AI provider, metrics, Facebook setup). Check the code before relying on a status line; some notes predate later changes.
- `training/` — user training slides (HTML/PDF) generated from `output/vertmonhub-training/`.
- `meta-review/` — Meta app review material.
- `vertmon-llc/` — client presentation artifacts.
- `archive/` — dated reviews, audits, roadmaps and superseded design plans. History only; they describe the code at the time they were written.

`CLAUDE.md` at the repo root is the maintained summary of architecture and the rules that must not regress.
