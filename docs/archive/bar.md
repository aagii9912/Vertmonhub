# Attio bar — Vertmon Hub dashboard

Reference: [Attio Web Screen on Mobbin](https://mobbin.com/explore/screens/50e23384-5853-455c-9e3a-6ef80b2ec216), inspected 2026-09-14.

This is a testable visual bar for the dashboard redesign. It extracts mechanisms from the reference; it does not copy Attio content or branding.

1. The desktop shell has one narrow, persistent navigation rail. Navigation is grouped and compact; only the current destination receives a quiet filled state.
2. Each workspace begins with a single, short object context line. It contains the current view or object name and only its essential utility actions; it is not a marketing-style page hero.
3. Saved views, sorting, filtering, and bulk actions form a separate compact control strip immediately above the work area. Controls remain inline until the viewport cannot fit them.
4. Record-oriented work uses a continuous table or timeline with one-pixel dividers. It does not turn every row, metric, or field into a raised card.
5. Table headers are quieter than values, columns align across rows, and normal desktop rows remain within the dense 32–40px range. Mobile rows may grow only to preserve a 44px tap target.
6. Blue appears only to identify an active selection, editable value, focused control, or primary action. Neutral surfaces and borders carry the rest of the hierarchy.
7. Empty result space stays calm and useful: a short explanation and one next action are sufficient. Decorative KPI blocks do not fill a data workspace when they do not help the task.
