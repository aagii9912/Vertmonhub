## 2. v3 архитектур (гибрид)

```
POST /api/ai-assistant/stream
  prepareAssistantRequest  (RBAC, shop, мэдлэг, ярианы хураангуй)
  runOrchestrator
    system  = persona + домэйн (cache) | shop мэдлэг + memory (cache) | огноо/хэрэглэгч/хураангуй
    tools   = dataToolsForPerms(RBAC) + ask_user + delegate_to_specialists
    runLoop (claude-opus-5, streaming, adaptive thinking, effort=medium, ≤8 раунд)
      tool_use → executeDataTool(confirm=false) → preview → pendingAction
               → delegate → runAgent × N зэрэг (claude-sonnet-5, агентын tool дэд олонлог)
               → ask_user → clarify event, loop зогсоно
  persistAssistantExchange → maybeUpdateSummary (24+ мессеж)
```

Файлууд: `lib/ai/claude/{client,tools}.ts`, `lib/ai/orchestrator/{loop,prompt,memory,runAgent,index,agents,types,http}.ts`. `planner.ts` устсан.

Event-үүд (SSE): `status`, `tool_start/tool_done` (id, tool, summary, agentId?), `step_start/step_done` (дэд агент), `token/token_reset`, `clarify`, `done` (+`clarification`), `error` (+`code`).

## 4. Wave 1 (2026-09-12, дараагийн commit) — «бүх ажлаа AI-д хэлээд хийлгэх»

Зорилго: борлуулагчийн өдөр тутмын үйлдлийг чатаар. Хийсэн:
- **Service давхарга**: `ViewingService.updateViewing/listViewings`, `TaskService`, `PaymentService.addPayment/updatePayment` (касс орлого автомат), `recordLeadContact`. API route-ууд (`viewings/[id]`, `tasks`, `contracts/[id]/payments`, `leads/[id]/activities`) эдгээрт суусан → гараар ба AI-аар ижил side-effect.
- **12 шинэ tool** (`data-assistant/actions.ts`): дуудлага бүртгэх, follow-up, уулзалтын үр дүн/зөөх, хувийн ажил, төлбөрийн хуваарь, лид шилжүүлэх.
- **Эрсдэлээр ялгасан баталгаажуулалт**: `AUTO_TOOL_NAMES` (буцаах боломжтой) картгүй шууд; устгах/төлбөр/шилжүүлэлт карт. Төлбөрийн tool-уудыг «үргэлж зөвшөөрөх»-д цээжлэх боломжгүй.
