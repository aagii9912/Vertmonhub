# Нийтийн лидийн төслийн холбоос

`POST /api/leads` нь байгууллагын эхний бүртгэл эсвэл form-ийн өгсөн нэрээр төсөл таахгүй. Нийтийн form-ийн төсөл серверийн тохиргооноос тогтоно. Төслийн UUID байхгүй, хүчингүй, байгууллагатай зөрсөн эсвэл уншилт амжилтгүй бол шинэ лид хадгалахгүй, `503` буцаана.

Нэг төсөлтэй form-д `LEAD_PROJECT_ID`-г `/admin/projects` дахь бодит төслийн UUID-аар тохируулна. Лидийн `shop_id` нь тэр төслийн `shop_id` байна. `LEAD_SHOP_ID` тохируулсан бол төслийн байгууллагатай яг таарах ёстой.

Олон төслийн сайт нэг endpoint ашигладаг бол `LEAD_PROJECT_ORIGINS`-д JSON object өгнө. Түлхүүр нь `https://domain.mn` хэлбэрийн бүтэн origin, утга нь бодит төслийн UUID байна. `www` болон үндсэн домэйныг тусад нь бүртгэнэ. Энэ тохиргоо өгсөн үед mapping-д байхгүй origin-д `LEAD_PROJECT_ID` fallback ашиглахгүй. JSON дахь UUID-г төслийн нэрээс эсвэл өөр төслийн UUID-аас хуулж тааж болохгүй.

`LEAD_ALLOWED_ORIGINS` нь өмнөх шиг CORS/origin зөвшөөрлийг удирдана. `LEAD_PROJECT_ORIGINS` нь төслийн холбоосыг удирдана. `LEAD_WELCOME_SITE_URL` нь зөвхөн угталтын имэйлийн холбоос; төслийн холбоос болгож ашиглахгүй. `projects` хүснэгтэд баталгаажсан вэб origin багана байхгүй тул сайтаас төсөл автоматаар таахгүй.

Нэвтэрсэн ажилтны `/api/leads` хүсэлт `leads` бичих эрх, өөрийн байгууллага, төслийн харьяаллын шалгалтыг давна. Ажилтан `project_id` UUID илгээж болно; өгөөгүй бол дээрх серверийн тохиргоог ашиглана. Менежерийн канон нэрийг идэвхтэй бүртгэл болон тухайн төслийн холбоосоос батална. Нийтийн хүсэлтийн `project_id` төслийн холбоосыг өөрчлөхгүй.

Хариу нь `{ success: true, receipt_id }` байна. Харилцагчийн утас, имэйл, дотоод тэмдэглэл, хариуцагч болон бусад хувийн талбар буцаахгүй. Өмнөх лидийн `project_id`-г нөхөхгүй. Энэ өөрчлөлт environment тохируулах, production migration эсвэл deployment хийхгүй.
