**Migration** `supabase/migrations/20260629120000_db_audit_fixes.sql` — хэрэглэхэд бэлэн (`supabase db push`):

**Код (хэрэгжсэн, typecheck/build/174 тест ✓):**

- KB `batchUpsertKnowledge` → ганц `upsert`.

**2-р багц — Hygiene migration** `supabase/migrations/20260629130000_db_audit_hygiene.sql` (non-destructive, auto-applicable):
- `updated_at` + trigger (chart_of_accounts, vendors, satisfaction_surveys).
- `customers.phone` → text.
- Soft-delete индексүүд → partial (`WHERE deleted_at IS NULL`).
- Одоо байгаа `NOT VALID` CHECK-уудыг `VALIDATE` (зөрчилтэй бол алгасна, migration унахгүй).

**3-р багц — Гараар ажиллуулах** `supabase/manual/` (өгөгдөл хөнддөг/destructive тул auto-apply-д ОРООГҮЙ, staging-д хянаж ажиллуулна):
- `2026-06-29_contract_dedup_unique.sql` — давхардсан гэрээг soft-delete (буцаах боломжтой) + partial UNIQUE.
- `2026-06-29_drop_legacy_ecommerce.sql` — products/orders/order_items/discount_schedules + orphan FK багана устгах (DESTRUCTIVE).

**Орхисон (зориуд):**
- `user_roles.role → roles(name)` FK — roles хүснэгтэд бүх role нэр (super_admin багтаан) байгаа эсэх батлагдаагүй тул орхив (буруу бол role олголтыг эвдэнэ). Hygiene migration-д заавартай тэмдэглэв.
- RLS per-row `auth.uid()` боолт — цэвэр performance lint, security/correctness нөлөөгүй, churn өндөр тул орхив.
- `check_admin_user` устгах — `20260609130000` "ашиглагдаж байгаа" гэж тэмдэглэсэн тул орхив.

> ⚠ Migration-ийг production-д хэрэглэхээсээ өмнө staging дээр шалгаарай. RLS policy өөрчлөлт тул browser-direct query-тэй дашбордын хэсгүүдийг (RBAC, marketing) нэг удаа гараар шалгах нь зүйтэй.

## Хураангуй

Хамгийн чухал нь **санхүүгийн тайлан буруу тоо гаргаж байгаа** явдал: `finance/reports`, `ar-aging` болон AI туслахын гэрээ нэгтгэх кодууд бүгд хуудаслалтгүй `select` ашигладаг тул Supabase-ийн 1000-мөрийн анхдагч хязгаараар чимээгүй тасарч, амьд Mandala үйлчлүүлэгчийн ~1617 гэрээний ~38% орхигдон, нийт орлого/НӨАТ/авлага бодит тооноос ердөө ~2/3 хэрэгтэй харагдаж байна — энэ нь гүйцэтгэлийн биш, **санхүүгийн алдаатай тоо**.

Аюулгүй байдлын талаас олон tenant-ийн тусгаарлалт эвдэрсэн: marketing хүснэгтүүд дээрх `USING(true)` policy, `user_roles`/`projects` дээрх задгай SELECT, RLS огт асаагаагүй webhook хүснэгтүүд, `property-images` bucket-ийн эзэмшигч шалгахгүй бичих эрх — нэвтэрсэн ямар ч хэрэглэгчид бусад tenant-ийн өгөгдлийг унших/өөрчлөх боломж олгож байна.

## Дунд зэрэг (Medium)

- **`property_contracts` композит индекс дутуу** — `(shop_id, contract_date DESC)` ба `(shop_id, contract_status)` нэмэх (одоо бүгд single-column). Read path `deleted_at` шүүдэггүй тул partial predicate БИШ.
- **`ai_analytics.customer_id` (SET NULL) индексгүй** — `CREATE INDEX … (customer_id) WHERE customer_id IS NOT NULL;`
- **Polymorphic/bare-uuid холбоос FK/CHECK-гүй** — `ai_attachments(entity_type, entity_id)`; actor багана (`ai_conversations.user_id`, `push_subscriptions.user_id`, `leads.assigned_to`, `finance_transactions.created_by`, `vendor_bills.approved_by/created_by`) `auth.users`-руу FK-гүй. Хамгийн багадаа `ai_attachments`-д `CHECK (entity_type IN ('property','lead','customer','contract'))`.
- **`handle_new_user()` / `handle_new_admin()` SECURITY DEFINER функц `search_path`-гүй** — trigger устсан ч функц үлдсэн; `handle_new_admin` super_admin болгодог тул латент эрсдэл. DROP эсвэл `SET search_path = public, pg_temp`.
- **HubSpot CSV import N+1** — `customers/import/hubspot/route.ts` (52-90): мөр бүрд SELECT + INSERT. Batch `.in()` lookup + chunked insert.
- **HubSpot API sync N+1** — `integrations/hubspot/sync/route.ts` (147-187): ижил pattern, max 5000.
- **Leads жагсаалт endpoint хуудаслалтгүй** — `dashboard/leads/route.ts` GET (22-33) `select('*')` хязгааргүй. `parsePagination`/`buildPageMeta` хэрэглэх.
- **Knowledge-base import нэг upsert биш** — `admin/import/route.ts` `batchUpsertKnowledge`/`importLoanInfo`. `UNIQUE(shop_id, category, key)` БАЙГАА тул `upsert(…, { onConflict: 'shop_id,category,key' })`.
- **Давхардсан permissive SELECT policy** — `customers`, `chat_history` дээр 008-era + 002-era policy хоёулаа OR'd (гүйцэтгэл). Хуучныг DROP.

- 3 SECURITY DEFINER функц `search_path`-гүй: `archive_old_chat_history`, `purge_archived_chat_history`, `cleanup_expired_ai_memory`.

- Dead exposed SECURITY DEFINER `check_admin_user(text)` (байхгүй `admin_users` руу хандана) → DROP.
